### 一键部署（推荐）

```bash
# 首次：安装 CLI 并登录（浏览器扫码，只需一次）
npm i -g @cloudbase/cli
tcb login

# 同步公共模块 + 部署全部云函数
npm run deploy:cloud

# 只部署指定函数
npm run deploy:cloud -- --only goods,meta,favorite
```

### 差异对比后上传（推荐日常）

对比本地源码哈希与云端已部署代码，**只上传有变更的函数**：

```bash
# 预览差异（不上传）
npm run push:cloud

# 上传有差异的函数
npm run push:cloud -- --yes

# 只检查/上传指定函数
npm run push:cloud -- --yes --only wiki,goods

# 强制与云端逐个下载比对（更准，较慢）
npm run push:cloud -- --remote

# 强制上传全部（等同 deploy:cloud 的选择性超集）
npm run push:cloud -- --yes --all
```

上传成功后会在 `scripts/.cloud-functions-manifest.json` 记录哈希，下次未改动的函数可跳过下载比对。

## 常见问题

### 提示「项目根目录下没有找到 app.json」

Taro 会把小程序产物编译到 `dist/`，**仓库根目录本身没有 `app.json`**，按下面顺序排查：

1. **先编译**：在项目根执行 `npm run dev:weapp`（开发）或 `npm run build:weapp`（上传前），等终端出现 `Compiled successfully`。
2. **打开正确目录**：微信开发者工具导入 **`FanYuFlowerShop` 仓库根目录**（含 `package.json`、`project.config.json` 的那一层），不要只打开 `dist/` 或 `src/`。
3. **确认产物存在**：根目录下应有 `dist/app.json`（`dist/` 在 `.gitignore` 中，克隆后需先编译才会生成）。
4. 仍报错时：开发者工具 → **关闭项目** → 重新导入根目录 → 「清缓存 → 全部」→ 再点编译。

### 上传时提示「无依赖文件」或 `.LICENSE.txt (packOptions.ignore)`

- **无依赖文件（`sub-common/*.js` / `*.wxss`）**：Taro 在顾客/商家两个分包共用组件时，可能额外生成一组 **template/style 分块**并复制到各分包 `sub-common/`，但页面实际 `require` / `@import` 的是另一组 hash。微信上传时会自动跳过这些无引用文件——**不影响运行，也不影响已上传的包体积**。
  - 常见对应组件：`OrderListCard`、`OrderListStatusTabs`、`OrderStatusSteps`、`WikiCareTrimGuide`、`GoodsNameTypeahead`。
  - 构建后 `scripts/prune-sub-common.js` 会自动删除无引用 chunk，减少上传提示；若仍看到，可 `rm -rf dist && npm run build:weapp` 全量重编。
- **页面路径不一致**：若提示的是整页目录缺失（例如旧的 `mine/other` 路由），重新执行 `npm run build:weapp` 后，对应分包下应有完整的 `index.js / json / wxml / wxss`。
- **`.LICENSE.txt`**：Webpack 生成的许可证旁注文件，构建脚本会自动删除且已在 `packOptions.ignore` 中忽略，不影响上传，可忽略。

### 体验版 / 真机商品图不显示

Cloud Console 里 `coverImageUrl` 已有 `https://`，但手机仍无图，通常是下面两类原因之一：

**A. downloadFile 合法域名未配置（HTTPS 临时链）**

1. 打开 [微信公众平台](https://mp.weixin.qq.com) → 开发 → 开发管理 → 开发设置 → **服务器域名**
2. 在 **downloadFile 合法域名** 增加云存储 CDN 域名（与 Console 里 `coverImageUrl` 的 host 一致），例如：  
   `636c-cloud1-d4gygenkwbed9bb6c-1444200315.tcb.qcloud.la`
3. 或在 **微信开发者工具 → 云开发 → 设置** 中使用「一键配置安全域名」

开发者工具可勾选「不校验合法域名」，**体验版/真机会强制校验**，故仅工具里正常、手机不行时优先查此项。

**B. 本地仍是旧版商品缓存（无 coverImageUrl）**

- 删除小程序重新进入，或清除 Storage 里 `goods:public` 前缀项  
- 代码已把缓存键升为 `v2`，重新上传体验版后会自动拉新数据

**C. 云存储权限（可选替代方案）**

将 `goods/` 目录设为 **所有用户可读，仅创建者可写** 后，前端可直接用 `cloud://` 展示（已在代码中作 fallback）；否则必须走 HTTPS + 合法域名。
