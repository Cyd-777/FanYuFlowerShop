# 搜索体系 · AI 搜索策略

> **更新**：2026-07-08  
> **关联**：搜索体系模块 · AI 导管模块 · 智库模块

---

## 一、核心原则

### 1. 模型冗余（抽象 AI 层）

当前用云端 DeepSeek，未来必然切换端侧模型。AI 调用层必须抽象：

```
功能代码
    │
    ▼
  AI 接口层（abstract）
    ├── 当前：cloudfunctions/ai（DeepSeek 云端）
    └── 未来：端侧 ONNX 推理（wx.createInferenceSession）
```

- 所有业务代码不直接调 DeepSeek API
- 统一走 `@/modules/ai/` 或云函数 `ai` 的 action 入口
- 切换模型时只替换实现层，业务代码不动

### 2. AI 赋能，减少代码量

AI 的目的是**替代手写规则/字典/穷举匹配**，不是增加复杂度。能用 AI 一句提示词解决的就不要写 50 行条件判断。

| 场景 | 之前 | 之后 |
|------|------|------|
| 搜索预判 | 语义字典（覆盖极有限） | AI 实时生成 |
| 搜索匹配 | 分词 AND 包含 | AI 解析口语→结构化查询 |
| 导购推荐 | 无 | AI 推荐成品+花材 |

## 二、搜索预判升级

### 现状

输入时预判只支持**前缀匹配**（搜"玫"→"玫瑰"），不支持语义（"送长辈"无结果）。

### 方案：AI 生成预判

```
用户输入 "送长"
    │
    ▼
  AI Suggest（cloudfunctions/ai · new action）
    │  输入：部分输入 + 已匹配的精确结果
    │  输出：["送长辈", "送长辈的花", "送长辈推荐"]
    │
    ▼
  预判列表（展开在这些词上附加标签）
```

**不改造现有预判引擎**，只在其结果中插入 AI 生成的语义预判词。精确匹配结果（商品名/品种名）仍由现有引擎提供。

## 三、智库搜索页

### 交互流程

```
金刚区「智库搜索」入口
    │
    ▼
  智库搜索页（新页面）
    │
    ├── 搜索框（吸顶）
    │
    ├── 热门搜索词条（常用花卉/场景，点击即搜）
    │
    └── 搜索结果
        ├── 匹配的智库词条（品种卡片）
        ├── 匹配的商品（商品卡片，可选）
        └── AI 推荐（"送长辈"→词条+推荐理由）
```

### 页面布局

```
┌─────────────────────────────┐
│  ⌕ 搜索花材/场景...  [搜索]  │ ← 输入聚焦后吸顶
├─────────────────────────────┤
│                             │
│  热门搜索                     │
│  [玫瑰] [百合] [送长辈]       │ ← 点击即搜
│  [康乃馨] [向日葵] [花期多久]  │
│                             │
├─────────────────────────────┤
│  → 搜索结果（搜完后）          │
│                             │
│  ┌─────┐ ┌─────┐            │
│  │词条卡│ │词条卡│            │
│  └─────┘ └─────┘            │
│  ┌─────┐ ┌─────┐            │
│  │商品卡│ │商品卡│            │
│  └─────┘ └─────┘            │
└─────────────────────────────┘
```

### 搜索逻辑

用户输入 → 同时执行：

| 路 | 搜索目标 | 返回 |
|----|---------|------|
| 1 | 智库词条（品种名/别名/标签） | 匹配的词条卡片 |
| 2 | 商品（名称/花材/描述） | 匹配的商品卡片 |
| 3 | AI 语义解析（口语化） | 解析后转路由 1/2，外加推荐理由 |

## 四、导购与智库的关系

```
用户搜索 "适合送长辈的花"
    │
    ├── 智库有匹配词条（品种关联了 occasions:["长辈"]）
    │   └── 直接展示词条 + 关联商品
    │
    └── 智库无匹配
        └── AI 解析意图 → 推荐适合场合的词条
            └── 展示推荐词条（标注"AI 推荐"）
```

**核心**：搜索结果优先展示智库词条，而非仅商品。有些花店不进的花，用户也能在智库看到、了解。
