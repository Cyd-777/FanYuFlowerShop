> **所属**：[样式体系模块](./样式体系模块.md)  
> **适用范围**：`src/components/`、`src/pages/`、`src/pagesCustomer/`、`src/pagesMerchant/`

## 一、Less 编写规范

### 1.1 导入令牌

所有含有 `@color-` / `@font-size-` / `@radius-` / `@spacing-` 变量的 `.vue` 文件，必须在 `<style>` 第一行导入：

```less
<style lang="less">
@import '@/styles/tokens.less';
```

### 1.2 禁止硬编码色值

❌ 错误：
```less
color: #333;
background: #f5f5f5;
border: 2rpx solid #eee;
```

✅ 正确：
```less
color: @color-text-primary;
background: @color-bg-muted;
border: 2rpx solid @color-border;
```

例外：纯白（`#fff` / `#ffffff`）、纯黑文字（极少场景）无需定义令牌。

### 1.3 选择器命名

- 使用**中划线 kebab-case**，如 `.goods-card`、`.filter-tabs`
- 避免 ID 选择器（#id），用 class
- 嵌套层级不超过 3 层

```less
// ✅ 推荐
.goods-card {
  &__title { ... }
  &__price { ... }
  &--sold-out { ... }
}

// ❌ 避免
.goods-card .info .title .text { ... }
```

### 1.4 样式作用域

- 组件样式**默认全局**（Taro / Vue SFC 中不加 `scoped`，由 BEM 命名区分）
- 如需隔离，用嵌套 class 而非 `scoped` 属性（小程序的 scoped 行为与 Web 不同）

## 二、组件结构规范

### 2.1 模板顺序

```
<template>
  <view class="page-xxx">        ← 根节点：page-{模块名}
    <AppNavBar />                 ← 导航栏
    <!-- 内容区 -->                ← 业务内容
  </view>
</template>
```

### 2.2 Script 顺序

```
1. import 外部库 / 工具函数
2. import 组件
3. import 类型
4. import composables / stores
5. 常量（uiText_xxx 等）
6. reactive state（ref / computed）
7. 生命周期（onLoad / onShow 等）
8. 业务函数
```

### 2.3 样式块顺序

```
1. @import tokens
2. 页面根节点（.page-xxx）
3. 页面布局（flex、grid）
4. 子组件容器
5. 业务元素
6. 修饰态（.active、.disabled）
7. 响应式（极少用）
```

## 三、通用组件模式

### 3.1 卡片容器

```less
.card {
  background: @color-bg-card;   // #fff
  border-radius: @radius-md;    // 16rpx
  padding: @spacing-sm;         // 16rpx
}
```

### 3.2 列表项

```less
.list-item {
  display: flex;
  align-items: center;
  padding: @spacing-sm;
  background: @color-bg-card;
  border-bottom: 2rpx solid @color-divider-light;
}
```

### 3.3 标签 / 徽标

```less
.tag {
  display: inline-block;
  padding: 4rpx 16rpx;
  font-size: @font-size-xs;     // 22rpx
  border-radius: @radius-sm;    // 8rpx
  color: @color-text-secondary;
  background: @color-bg-muted;

  &--brand {
    color: @color-brand;
    background: @color-brand-light;
  }
  &--success {
    color: @color-success;
    background: @color-success-bg;
  }
  &--danger {
    color: @color-danger;
    background: @color-danger-bg;
  }
}
```

### 3.4 按钮

```less
.btn {
  display: flex;
  align-items: center;
  justify-content: center;
  padding: 16rpx 32rpx;
  font-size: @font-size-lg;     // 28rpx
  border-radius: @radius-pill;  // 48rpx

  &--primary {
    background: @color-brand;
    color: #fff;
  }
  &--outline {
    background: transparent;
    border: 2rpx solid @color-brand;
    color: @color-brand;
  }
  &--muted {
    background: @color-bg-muted;
    color: @color-text-secondary;
  }
}
```

### 3.5 骨架屏

使用 `<GoodsCardSkeleton>` 组件：
```vue
<GoodsCardSkeleton variant="row" :count="5" />
```

- `variant`：`"row"`（行式）| `"card"`（卡片式）
- 颜色继承 `@color-bg-placeholder`（`@gray-200`）

## 四、颜色使用规范

| 语义 | 字体色 | 背景色 | 边框色 |

| **品牌** | `@color-brand` | `@color-brand-light` | `@color-brand-border` |

| **警告** | `@color-warning` | `@color-warning-bg` | — |

| **Wiki** | `@color-wiki-purple` | `@color-wiki-purple-bg` | — |

## 五、页面布局规范

### 5.1 导航栏模式

| 模式 | 说明 | 配置 |
|------|------|------|
| `overlay` | 透明浮层，不占文档流 | Tab 页（首页、商城、百科等） |
| `spacer` | 固定条 + 占位块 | 子页面 |
| `flow` | 文档流内嵌 | 跟随 scroll-view 滚动 |

配置在 `src/config/pageNav.ts` 的 `PAGE_NAV` 中。

导航栏安全区：
```less
.page-nav-overlay-safe {
  box-sizing: border-box;
  padding-top: var(--nav-total-height, 0px);
}
```

### 5.2 搜索栏

- 使用 `<AppSearchInput>` 组件
- 粘性定位：`position: sticky; z-index: 95`
- 展开搜索模态时 `z-index: 200`

### 5.3 滚动容器

```less
scroll-view {
  height: 100%;          // 需明确高度
  overflow-y: scroll;    // 或 overflow: hidden
}
```

**重要**：小程序中 `scroll-view` 必须有固定高度才能滚动。

## 六、图标使用规范

### 6.1 当前策略

所有图标**暂用 emoji**，待 LOGO 完成后再设计统一图标方案。

### 6.2 AppIcon 组件（备用方案）

当后续切回图标方案时，使用：
```vue
<AppIcon type="返回" :size="24" />
```

图标注册在 `src/assets/icons/index.ts`，中文键名。

### 6.3 不使用的方案

- ❌ SVG 内联（小程序不支持）
- ❌ iconfont 字体（跨端兼容问题）
- ❌ 自定义图标组件（当前阶段不引入）

## 七、动画与过渡

- 少量使用 `transition`，避免复杂 CSS 动画
- 页面切换由 Taro 框架控制，不需要自定义
- 下拉展开/收起用 `transition: height 0.3s` 或 `opacity 0.2s`
- 禁用 `animation` 属性 — 小程序性能有限

---

## 八、样式检查清单

开发/修改组件样式后，检查以下项：

- [ ] 所有颜色使用 `@变量`，无硬编码十六进制
- [ ] 所有字号使用 `@font-size-*` 令牌
- [ ] 圆角使用 `@radius-*` 令牌
- [ ] 间距使用 `@spacing-*` 或合理 rpx 值
- [ ] `<style>` 首行有 `@import '@/styles/tokens.less'`
- [ ] 选择器使用 kebab-case
- [ ] scroll-view 有明确高度
- [ ] 颜色语义正确（品牌色用 `@color-brand`，不要用 `@color-success`）
