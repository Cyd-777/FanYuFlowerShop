# 商品关联

> **所属**：[智库模块](./智库模块.md)  
> **状态**：已迁入策略

## 目的

商品上的花材编号（`flowerKind*` / `flowerVariety*`）↔ 智库条目匹配，在 [商品详情](./商品模块-商品详情.md) 展示百科内容，**免去重复维护商品详情养护正文**。

## 策略原话

- “商品页给智库导流当前已经做完了。商品选择了品类和品种后，就会在详情中显示对应的智库内容。”
- “这些花卉词条会在对应的花卉商品的详情内。这样我们就免去了给商品维护详情信息的工作。”
- “智库对于对应花卉词条下有花语信息、百科以及养护指南。”
