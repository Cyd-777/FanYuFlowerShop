- **商户加花 → 只建百科词条**：新品种入库时在百科加词条 + 建商品时选该品种 → 分类可自动匹配（见 [分类管理 · 按单位拆分](./分类管理模块-按单位拆分.md)）。
- 维护侧配图走 [素材管理 · 智库配图](./素材管理模块-智库配图.md)。

## 云端

| action | 说明 |
|--------|------|
| 维护 CRUD | 商家端词条读写 |
| `syncKindProfiles` | 批量写回品类资料 |

```bash
npm run sync:wiki-profiles   # 部署 wiki 后
```
