# 欢迎模态

> **所属**：[启动与授权模块](./启动与授权模块.md)  
> **状态**：待开发（立项见 [🎛️ CURRENT · 启动授权（§7.11）](./🎛️%20CURRENT.md)）

## 目标流程（新 API，非 getUserProfile）

```text
登录页
  ├ 勾选：头像告知
  ├ 勾选：昵称告知
  ├ 勾选：用户协议 + 隐私政策（主项，未勾不可登录）
  └ 微信一键登录 → OpenID（云函数 loginWechat）

登录成功（首次或资料未完善）
  └ 欢迎 / 资料浮层
       ├ chooseAvatar + nickname 输入
       ├ 可选：开启通知（订阅消息，拒也进）
       └ 保存 → 进首页 / 工作台

已有 token + 完整资料 → 跳过浮层
后续修改 → 「我的 → 编辑资料」
```

## 实现注意

- 头像昵称须在用户**主动点击**选/填后获取，不可绑在登录按钮上一次性静默授权。
- 订阅消息按策略**不阻断**进入；与登录 tap 或浮层内按钮衔接均可。
- 协议同意记录建议带**版本号**，便于政策更新后重新确认。
