# 智能粘贴 · 大模型提示词

> **所属**：[智库模块 · 词条维护](./智库模块-词条维护.md)  
> **状态**：已启用 — 替代「外部 API 一键预填」的主路径

## 为何用提示词而不是外部 API

[外部预填讨论稿](./智库模块-外部预填与笔记编辑.md) 结论：维基 / GBIF 等 **填不满** 本店词条模板（瓶插养护、花语、公共块 ID）。  
更稳妥的做法：用 **结构化提示词** 让大模型按章节与**公共块词表原词**输出 → 粘贴进 **智能识别** → **文本映射为块 ID** → 字段对照 → **人工勾选**应用。

## 使用步骤

1. 商家词条编辑页填写 **种类**（必填）、**品种**（可选）。
2. 展开 **智能识别** → 点 **复制提示词**。
3. 粘贴到 ChatGPT / Claude / 通义等对话，等待模型输出正文。
4. 将模型输出 **全文** 贴回智能识别文本框 → **识别并对照** → 勾选（含块 ID 映射项）→ **应用所选**。
5. 保存前扫一眼对照表；未识别或标「待核」的项在表单模式补选。

## 输出格式（须遵守）

模型输出须含 **7 个二级标题**（与 `parseWikiSmartPaste` 对齐）：

| 章节 | 识别用途 |
|------|----------|
| `## 介绍` | 背景长文、学名、育种、分类线 |
| `## 图鉴` | 花径、瓣数、色泽、茎叶、香气、园艺分类、主产区 |
| `## 花期` | 瓶插天数 `约 7—10 天` |
| `## 养护` | 换水、修剪、水位；tips 以「避免/注意/建议」开头 |
| `## 花语` | 核心花语、段落、场合、色彩寓意 |
| `## 易混` | `品种名—区别` 每行一条 |
| `## 搜索` | `别称：`、`标签：` |

完整提示词由 `buildWikiSmartPastePrompt()` 动态生成（含当前种类、公共块词表）。

## 块 ID 字段：可以映射，靠人工审核

外部 API **拿不到**块 ID；大模型 + 智能识别 **可以**，流程是 **标签/词表匹配 → 建议块 ID → 对照表勾选**。

| 块字段 | 映射方式 | 对照展示 |
|--------|----------|----------|
| `taxonomyRef` | 正文含 `蔷薇科蔷薇属` 等分类线；或按表单种类推断 | 已支持 |
| `horticulturalGroup` | 正文含园艺分类标签（如 杂交茶香） | 已支持 |
| `productionRegions` | 正文含产区标签（如 中国云南、哥伦比亚） | 已支持 |
| `featureRefs` / `flowerForm` | 正文含特征 chip 标签原词 + 关键词兜底 | 已支持 |
| `careBaseRef` | `养护底稿：玫瑰` 或养护章 + 种类 → 默认 care 块 | **已补强** |
| `pairing` 搭配 | 暂未解析 | 仍手填 |

**原则**：识别结果一律进「字段对照」表，默认勾选有变化的项；商家 **看一眼再应用** — 人工审核没有问题。

## 纯文本 / 暂未映射

| 字段 | 说明 |
|------|------|
| `pairing` 搭配 | 智能识别暂未覆盖，表单手填 |
| 覆盖内置 overlay 策略 | 与是否映射无关；保存规则不变 |
