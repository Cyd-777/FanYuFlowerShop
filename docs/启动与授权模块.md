# 启动与授权模块

> **分层**：附加  
> **状态**：已迁入策略

## 策略

首次进入获取 OpenID、头像、用户名；一次性欢迎模态 + 订阅消息邀请。

### 策略原话（摘要）

- 第一次进入必获 OpenID、头像、用户名。
- 只显示一次的欢迎模态 + 「开启通知」按钮；不同意也可进；按钮保留在「我的」页。
- 通知权限：初次打开可选勾选，**不影响**进入小程序。
- 可合并请求：微信名、头像、OpenID、订阅消息权限。

- 不阻断未授权用户浏览（通知可选）。
