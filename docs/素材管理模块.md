# 素材管理模块

> **分层**：强化  
> **状态**：已迁入策略

## 策略

商品图、Banner、智库配图等**云端素材**统一上传与管理；列表用缩略图，详情大图。

### 策略

- 图片**一定在云端**，占用加载带宽；与 [数据加载](./数据加载模块.md) 懒加载策略配合。
- 上传单张上限 10MB（已落地）。
- 不变的小图标**不**走素材库 → [导航与图标](./导航与图标模块.md)

- 不做 CDN 外的第二套存储体系。
