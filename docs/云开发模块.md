# 云开发模块

> **分层**：工程  
> **状态**：已迁入

## 策略

- 环境 ID：`src/config/env.ts` → `CLOUD_ENV_ID`
- 云函数目录：`cloudfunctions/`；小程序产物：`dist/`
- 顾客读公有数据走 `publicList` / `publicGet` 等，图片在云函数内换 HTTPS 链
- 写操作后 `cache_meta` bump；部署前 `npm run sync:cloud`

# 云开发说明

## 环境配置

| 配置项 | 位置 | 说明 |
|--------|------|------|
| 云环境 ID | `src/config/env.ts` | `CLOUD_ENV_ID` |
| 云函数目录 | `project.config.json` | `cloudfunctionRoot: cloudfunctions/` |
| 小程序输出 | `project.config.json` | `miniprogramRoot: dist/` |
