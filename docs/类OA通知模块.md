> **分层**：附加  
> **状态**：已迁入策略

## 策略

**人对人、业务到人**的主动通知：员工互发带业务属性的消息；系统向员工推送节日进货清单等。

### 策略要点

- 例：节日前向店员推送**节日相关进货提醒**，依据智库词条与关键词 / 标签。
- 属于智库**元数据 + 定时规则**，**不经过**顾客搜索框。
- 与搜索模块可并行开发，依赖智库 2.0 字段（`occasions` / 标签）逐步补齐。

### 策略原话（摘要）

- 类似 OA：员工之间相互发送、带业务属性的消息。
- 订单详情 / 商品编辑页：通知图标 → 选接收人 → 自动带订单号或商品名上下文。
- 节日前推送进货推荐清单；基于智库标签自动生成，OA 消息推送员工。

- 不做通用 IM；聚焦**业务通知**与**节日进货清单**。
- 体验细节记入 [体验台账](./体验台账模块.md)（待迁）。
