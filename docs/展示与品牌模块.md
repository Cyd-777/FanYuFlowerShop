## 策略

花是**情绪价值**载体，非纯物质消费；小程序视觉与促销表达需精心设计。

### 策略原话（摘要）

> **视觉约束**：促销与整体美术由你主导；不由 Cursor 默认实施。

- 90% 视觉元素需精心设计；促销显眼但**不抢眼**。
- 策略：**提高促销信息视觉重量，用稍淡的颜色**。
- 小礼品完全融入小程序「有方法但暂不扛」— 你和小程序体积都遭不住。

- Cursor 不默认做促销视觉 / Banner 美术定稿。
- LOGO / Tab 图标方向见 [图标与LOGO](./展示与品牌模块-图标与LOGO.md)。
