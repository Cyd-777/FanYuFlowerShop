# Bug 记录（重大代码缺陷）

## 文档目的

1. **积累经验**：重大缺陷的现象、根因、修法写清楚，以后碰到类似情况有文献可查、可学。  
2. **项目台账**：记录本项目**已修过的代码缺陷**，方便查「这个问题以前修没修过」；若同类现象再出现，可对照是**回归**还是**新根因**。

**与 [ux-improvements.md](./ux-improvements.md) 的分工**

| 文档 | 写什么 |
|------|--------|
| **本文** | 重大**代码错误**（错数据、崩溃、白屏、编译失败、缓存/logic 写错等） |
| **体验优化文档** | 交互、策略、展示、流程改进；未实现的产品设想 |

---

## 条目怎么写（模板）

- **现象**：用户/测试看到什么  
- **根因**：代码层原因（写清文件/逻辑，避免只写「已修复」）  
- **修复**：改了什么  
- **验证**：如何确认修好了  
- **若再出现**：先查本条目；若根因不同，**新开一条**并注明「与 xxx 条目区别」

## 已修复

### 商品列表/卡片图片污染

- **现象**：多张商品卡片显示同一张错图（详情也可能错）。  
- **根因**：`fetchPublicImageLocalPath` 本地文件名用 `encodeURIComponent(fileId).slice(0, 48)`，同云环境 fileID **撞名覆盖**（≠ 上传文件名重复）。  
- **修复**：`goodsImage.ts` fileId 哈希唯一路径；`GoodsImage.vue` `:key` 与刷新逻辑。  
- **验证**：体验版复测通过（2026-06-21）。  
- **若再出现**：查是否仍走代理写盘、是否清过旧缓存；HTTPS 链路过期多为裂图而非串图。

### 编辑资料保存后被冲掉

- **现象**：改昵称/头像后重进变回「花友xxxx」。  
- **根因**：`onShow` → `checkAccess` → `persistSession` 覆盖本地 `user_info`。  
- **修复**：`checkAccess` 不覆盖资料；`saveProfile` 回读；`fetchUserProfile` 合并缓存。  
- **验证**：需 `login` 云函数已部署。  
- **若再出现**：查 cloud `users` 是否写入、是否又有 session 逻辑写回 profile。

### 编译失败 → 无 `dist/app.json`

- **现象**：开发者工具报 `miniprogramRoot` 下无 `app.json`。  
- **根因**：编译失败（曾缺 `GoodsNewListingBadge.vue`），`dist/` 未生成。  
- **修复**：补组件 + 构建通过。  
- **若再出现**：先看 `npm run build:weapp` 是否报错，勿先改 `project.config.json`。

### 顾客首页白屏

- **根因**：Vue 页误用 `{{ }}` 模板写法；部分 NutUI 组件在小程序端异常。  
- **修复**：Vue 绑定 + 调整组件。  

### 「我的」页白屏（身份码）

- **根因**：二维码 1000+ `view` 节点，超小程序上限。  
- **修复**：Canvas 2D + 弹窗懒加载。  

### TabBar 图标路径不存在

- **根因**：tab 图标未生成/未 copy 到 `dist/`。  
- **修复**：`generate-tab-icons.js` + copy 配置。  

### 登录云函数/云初始化缺失

- **根因**：无 `login` 或未 `initCloud`。  
- **修复**：补齐云函数与配置。  

### 「行囊」误挂载（实现错误，已撤回）

- **根因**：半屏购物车提前挂到全部 `pagesCustomer`。  
- **处理**：删除挂载；交互规划见 **ux-improvements.md**。
