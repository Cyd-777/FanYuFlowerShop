# 下单确认

> **所属**：[订单模块](./订单模块.md)  
> **状态**：已迁入

## 范围

| 页面 / 能力 | 路径 | 状态 |
|-------------|------|------|
| 下单确认页 · 填单与提交 | `pagesCustomer/order/confirm` | ✅ |
| 地址选择 | 确认页内 | ⚠️ 地址簿见 [地址](./地址模块.md)；快照写入订单 |

## 流程

```text
购物车「结算」→ 确认页（核对商品、地址、备注）→ 提交 → order.create → 扣库存 → 跳转详情
```

定制花束与普通商品一样经购物车 → 确认页提交；行项目可带 `customSummary`。

## 云端

- `order.create` — 创建订单、服务端扣减库存
- 地址写入订单**快照**（姓名、电话、地址文本），不依赖后续地址簿变更

## 约定（闭环已拍板）

| 项 | 决策 |
|----|------|
| 付款 | 本阶段不接入微信支付；创建即「待处理」，商家线下收款 |
| 库存 | **创建订单时服务端扣减**；取消时回滚 |
| 定制花束 | 与普通商品同路径经购物车提交 |
