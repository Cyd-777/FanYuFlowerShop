> **状态**：已迁入策略

## 策略

智库是花店**知识中枢**，不只百科 Tab 一个页面。消费方包括：商品详情词条、商家建品选花、百科 Tab 搜索、未来顾客联合搜索、类 OA 节日进货提醒、识图入智库等。

**花店场景共识（2026-06）**

- 本店以**剪枝 / 鲜切花**为主，顾客拿回家**养在水里**；少量土培绿植。
- 顾客问法：**能开（养）多久？**、**怎么养？**、**怎么换水？** — 文案与搜索词按口语整理，少用「土培 / 水培」等专业术语。
- 养殖 Tab：**上方**插瓶 / 水养（默认展开）；**下方**土培参考（补充、可折叠）。

- **不**让搜索模块长期适配「旧智库」preview 整段子串匹配；先定智库查询请求结构，搜索只产出该结构（见 [搜索](./搜索模块.md)）。
- **不**在商品详情重复维护大段养护正文 — 词条即详情来源（见 [商品关联](./智库模块-商品关联.md)）。
- **不**覆盖干花、永生花等未拍板场景 — 以后追加。
- 未在售 / 本店不经营的花材可**隐藏词条**（预留，低优先级）。

## 勾连关系

| 消费方 | 依赖智库什么 | 是否依赖搜索框 |
|--------|--------------|----------------|
| 商品详情 ↔ 词条 | 花材编号（品类 / 品种）匹配百科条目 | 否 |
| 商家建品选花 | 花卉库 + 商品花材字段 | 否 |
| 百科 Tab 搜索 | 全文 / 分词 / 标签（2.0） | 是（仅百科页） |
| 顾客联合搜索（规划） | 同上，与商品结果分区 | 是 |
| 类 OA 节日进货（规划） | 节日、场景、应季花材等结构化字段 | 否 |
| 识图（规划） | 识别结果映射花材编号再查智库 | 否 |

**升级时不动项**：商品花材编号 ↔ 智库 `按编号匹配` 保持可用。
