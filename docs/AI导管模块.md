# AI导管模块

> **分层**：附加  
> **状态**：已迁入策略

## 策略

轻量模型作**导管**：图形识别 → 结构化 query → 对比智库 / 填表；减少用户手动操作，不替代搜索框 UI。

### 策略要点

- AI **只是导管**：识别准 + 特征词准 + 智库信息全，表单才准。
- **三套词典分离**：智库 / 顾客搜索 / 商户管理搜索，字典不同；AI 做「语义 → 结构化 query」。
- **识图进智库**：拍照 / 选图 → AI 导管 → 同一套智库查询约定（不走搜索框）。
- **输入预判指引**：比写死规则灵活；失败回退规则。

### 策略原话（摘要）

- 识别百合 + 黄百合 → 自动填位置、预选分类；新建 / 入库体验更好。
- 愿景：用户**只眼睛确认 + 点确认**；不准才手改。
- 可扩展：拍根部识数量、根据购买记录调排序（技术允许时）。

- **不替代**搜索框 UI。
- **不用**动辄几 G 的服务端大模型（见 [模型加载](./模型加载模块.md)）。
