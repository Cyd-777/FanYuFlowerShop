# 词条可视化

> **所属**：[智库模块](./智库模块.md)  
> **状态**：已迁入策略

## 现状

当前智库主要是**可视化的数据集合** — 图鉴 / 养殖 / 花语分 Tab 展示已有字段；尚未达到「查字典」式交叉检索体验。

## 目标（智库 2.0）

- 智库本质是**可查询的数据库**：直接查词条，或通过**关键词 / 标签组合**锁定词条（「查字典」）。
- 每个品种拥有一组**精确、结构化、可交叉筛选**的特征标签（例：黄色、浓香、卷瓣 → 搜「黄色 浓香」命中黄天霸）。
- **两层结构**：花卉种类 → 花卉品种。
- **本地包**：核心在售词条打包进分包，搜索优先本地，未命中再走云端（见 [模型加载](./模型加载模块.md)、[数据加载](./数据加载模块.md)）。

## 策略原话

- “当前的智库只是一个可视化的数据集合，没有做到一个智库该做的工作……说白了其实就是查字典。这些当前智库都不具备。”
- “我需要给每种花打标签……搜索时，不是扫全文，而是直接匹配这些标签。”
- “我们店中没有的花……也会选择性隐藏它的词条……保险的预留功能。”
- “核心在售花卉的词条，作为静态数据打包进小程序分包。”
