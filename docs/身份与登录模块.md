# 身份与登录模块

> **分层**：业务  
> **状态**：已迁入

## 策略

- **默认登录**：微信一键登录（小程序 openid）
- **手机号登录**：前后端已实现；UI 由 `src/config/login.ts` 的 `ENABLE_PHONE_LOGIN` 控制（当前 `false`）
- **资料完善**：「我的」→ 编辑资料，头像 / 昵称存云端
- 鉴权由云函数 `getWXContext().OPENID` 完成，客户端不传 openid
