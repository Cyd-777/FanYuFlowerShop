# 顾客浏览

> **所属**：[商品模块](./商品模块.md)  
> **状态**：已迁入

## 范围

| 页面 / 能力 | 路径 | 状态 |
|-------------|------|------|
| 首页商品展示 | `pages/home` | ✅ |
| 分类 Tab 商品列表 | `pages/category` | ✅ |
| 商品列表 | `pagesCustomer/goods/list` | ✅ |
| 购物车 Tab | `pages/cart` | ✅ 持久化、改数量、去结算 |
| 收藏列表加购 | `pagesCustomer/favorite` | ✅ 见 [收藏](./收藏模块.md) |

## 购物车 Tab（边界内）

- 本地持久化、改数量、删除、跳转详情
- 进入购物车时云端同步（下架移除、库存 / 价格更新）
- Tab 角标显示购物车商品总数
- 点击「结算」→ [下单确认](./订单模块-下单确认.md)

独立模块文档见 [购物车](./购物车模块.md)。
