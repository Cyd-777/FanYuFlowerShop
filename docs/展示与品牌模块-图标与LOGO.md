# 图标与LOGO

> **所属**：[展示与品牌模块](./展示与品牌模块.md)  
> **状态**：已迁入策略

> **品牌 / 视觉约束**：不由 Cursor 默认绘制。

## 策略原话（摘要）

- 图标要有花；**莲花弃用**（宗教贴近）。
- 倾向**视觉重量**，非清线条。
- 月亮门有意向但小程序图标切圆会被切掉 → 放弃。
- 网格渐变 + 水域透视 + 山茶花 + 深色淡雅底 + 水波纹 — 可转 Banner 方案。
- 山茶花可破型、负空间花蕊；成功则保留识别度。

## 工程侧

- 几乎不变的小图标（约 30–40 个）：Base64 PNG 打进分包 → [导航与图标](./导航与图标模块.md)
- Tab 图标仍走 `images/` 构建脚本
- **Tab 消息态 icon（铃兰）**：未读业务通知时「我的」Tab 切换为铃兰花朵造型 → [src/images/tab/README.md](../src/images/tab/README.md)（**设计待做**，当前占位）
