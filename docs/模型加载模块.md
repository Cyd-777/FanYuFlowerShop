# 模型加载模块

> **分层**：附加  
> **状态**：已迁入策略

## 策略

本地小模型作 AI 导管；**首次下载可接受**，之后每次打开静默加载。

### 策略归纳

- 不用几 G / 几十 G 大模型；要求：**快**、逻辑强、占用小、几乎不需生成能力。
- **服务端大模型不做**（带宽 / 性能压力）。
- 倾向**小模型加载在用户手机**；首次使用下载到本地可接受；每次打开须静默 mmap / 读入（200–500ms 级可接受）。
- **加载优先级**：**商品 P0 > 智库本地包 > 模型**。
- 商品列表分阶段加载（信息 / 图片分开）；图片懒加载 + 缩略图。

### 策略原话（摘要）

- 用户还在确认权限页时模型可已开始加载。
- 智库以**词条为单位**加载，不会一条卡死全部。
- 几十 M 模型如何处理是核心问题（非每次打开都慢）。

- 不在开小程序时阻塞 UI 等模型（若每次打开都慢则须换策略）。
