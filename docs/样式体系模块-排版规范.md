## 字号体系

所有字号使用 `rpx` 单位（小程序自适应）。定义在 `tokens.less` 的 L3 区。

| 令牌 | 值 | 典型用途 |
|------|-----|---------|
| `@font-size-xs` | `22rpx` | 辅助信息、标签、时间戳 |
| `@font-size-sm` | `24rpx` | 二级正文、列表副信息 |
| `@font-size-md` | `26rpx` | **默认正文** |
| `@font-size-lg` | `28rpx` | 正文强调、商品名、列表项 |
| `@font-size-xl` | `32rpx` | 小标题、价格数字 |
| `@font-size-2xl` | `36rpx` | 页面大标题 |
| `@font-size-price` | `40rpx` | 大号价格展示 |

### 常见字号对照

```
18rpx ─ 极少用（仅极紧凑场景）
20rpx ─ 极弱辅助信息，无对应令牌
22rpx ─ @font-size-xs   标签、时间、辅助文字
24rpx ─ @font-size-sm   胶囊按钮、筛选标签、二级信息
26rpx ─ @font-size-md   正文、商品简介、提示
28rpx ─ @font-size-lg   商品名、列表标题、按钮文字
30rpx ─ 无对应令牌（部分旧组件在用，建议迁移到 @font-size-xl 或 @font-size-lg）
32rpx ─ @font-size-xl   小标题、模块标题、价格
36rpx ─ @font-size-2xl  页面大标题
40rpx ─ @font-size-price 价格展示
```

### 最佳实践

- **正文优先用 `@font-size-lg`（28rpx）**，这是组件中最常见的字号
- **辅助信息用 `@font-size-xs`（22rpx）**，不要用 18rpx 或 20rpx
- **价格数字用 `@font-size-price`（40rpx）**，不用单独定义
- 不要直接写 `font-size: 30rpx` — 无对应令牌，建议改用 `@font-size-xl` 或 `@font-size-lg`

## 圆角体系

| 令牌 | 值 | 典型用途 |
|------|-----|---------|
| `@radius-sm` | `8rpx` | 小元素圆角、tag |
| `@radius-md` | `16rpx` | **默认卡片/容器圆角** |
| `@radius-lg` | `24rpx` | 大卡片、弹窗 |
| `@radius-pill` | `48rpx` | 胶囊按钮、搜索条 |
| `@radius-round` | `50%` | 圆形头像、图标容器 |

### 最佳实践

- **卡片/列表项用 `@radius-md`（16rpx）**
- **按钮用 `@radius-pill`（48rpx）** 或 `@radius-md`
- **小标签用 `@radius-sm`（8rpx）** 或 `999rpx`（全圆角 pill 标签）
- 避免直接写 `border-radius: 12rpx` — 无对应令牌（部分旧组件在用，可视情况迁移到 `@radius-sm` 或 `@radius-md`）

## 间距体系

### 外边距 / 内边距

| 令牌 | 值 | 典型用途 |
|------|-----|---------|
| `@spacing-xs` | `8rpx` | 元素间极小间隔 |
| `@spacing-sm` | `16rpx` | 列表项内边距、卡片 padding、gap |
| `@spacing-md` | `24rpx` | **页面/区块边距** |
| `@spacing-lg` | `32rpx` | 大区块间距 |
| `@spacing-xl` | `48rpx` | 页面底部留白、大分段间距 |

### 最佳实践

- **页面左右边距用 `@spacing-md`（24rpx）**
- **卡片内边距用 `@spacing-sm`（16rpx）**
- **flex gap 用 `@spacing-xs`（8rpx）或 `@spacing-sm`（16rpx）**
- **分段上下间距用 `@spacing-lg`（32rpx）或 `@spacing-xl`（48rpx）**

## 行高规范

小程序中不统一设置行高令牌，但建议以下惯例：

| 场景 | 行高建议 |
|------|---------|
| 单行文字 | `line-height: 1.4` 或 `1.5` |
| 多段正文 | `line-height: 1.6` |
| 标签/胶囊 | `line-height: 1.2` 或 `1.4` |
| 导航栏/按钮 | 通过 `height + line-height` 垂直居中 |

---

## 字体

- 不自定义字体，使用系统默认字体（`-apple-system`, `Helvetica Neue`, `PingFang SC` 等）
- 不使用 `font-weight` 的令牌变量，直接写 `font-weight: 500`（中粗）、`600`（半粗）、`700`（粗体）

---

## 单位

| 单位 | 适用范围 |
|------|---------|
| `rpx` | **所有长度**（width、height、padding、margin、font-size、border-radius） |
| `px` | 图标大小（AppIcon 固定 px）、与原生组件对齐的场景 |
| `%` | 百分比宽度、flex 布局 |
| `vw/vh` | 极少用，仅在 Timeline 等特殊场景 |
| `rgba()` | 半透明色 |

## 当前代码与令牌的差距

以下常见值在代码中出现较多但没有对应令牌，可以考虑后续补全：

| 值 | 出现次数 | 建议 |
|----|---------|------|
| `font-size: 30rpx` | 7 次 | 迁移到 `@font-size-xl(32rpx)` 或 `@font-size-lg(28rpx)` |
| `border-radius: 12rpx` | 12 次 | 迁移到 `@radius-md(16rpx)` 或 `@radius-sm(8rpx)` |
| `font-size: 20rpx` | 9 次 | 考虑新增 `@font-size-xxs: 20rpx` |
| `border-radius: 6rpx` | 5 次 | 迁移到 `@radius-sm(8rpx)` |
