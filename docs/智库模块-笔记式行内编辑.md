# 笔记式行内编辑

> **所属**：[智库模块 · 词条维护](./智库模块-词条维护.md)  
> **状态**：**P1 已实现**（预览壳 + 段落编辑 + 表单切换）；P2/P3 待续

## 需求（原话）

- **预览即编辑** — 维护时所见即顾客端详情，不在一长串表单里找字段
- **点击段落 / 标签修改** — 像笔记一样点哪改哪；公共块（分类、特征 chip）点选仍走现有浮动面板

与 [智能粘贴 · 大模型提示词](./智库模块-智能粘贴提示词.md) 互补：提示词负责「灌内容」，笔记式负责「改内容」。

---

## 目标体验

```text
商家词条编辑页
  ├ 默认：顾客端同款预览（Hero + 浮动面板 + 介绍 / 养护 / 花语 Tab）
  ├ 点击正文段落 → 浮层 textarea → 写回 form 对应字段
  ├ 点击 tag / chip / 场合胶囊 → 现有 picker 或专用浮层
  ├ 顶部：保存 · 切换「表单模式」（高级 / 公共块 / 搜索字段）
  └ 智能识别卡片保留在页顶或表单模式内
```

## 技术要点

- **复用而非重写**：优先 `@/pagesCustomer/wiki/detail` 已用的 section 组件（`WikiAtlasIntro`、`WikiCareSection`、`WikiLanguageSection` 等），加 `editable` + `@edit` 插槽或 emit。  
- **小程序限制**：长文用 `page-container` / 底部浮层 textarea，避免在 `scroll-view` 内嵌套可聚焦 input 导致滚动冲突。  
- **内置 overlay**：有 overlay 的词条预览仍展示拼装结果；云库字段覆盖规则与现编辑页 banner 一致。  
- **不替代**：智能粘贴、大模型提示词、公共块浮动面板仍保留。
