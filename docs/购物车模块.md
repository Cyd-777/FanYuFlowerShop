# 购物车模块

> **分层**：业务  
> **状态**：已迁入策略

## 策略

花店场景：购物车不是「目的地」，而是随时瞥一眼、继续逛的**临时行囊**。

### 交互定案（修订共识）

| 场景 | 形态 |
|------|------|
| **一级 Tab 页**（带底栏） | **保留 Cart Tab**；**不**显示「行囊」半屏 |
| **二级 / 三级顾客页**（无底栏） | 「行囊」FAB + **半屏**，便于选购途中瞥一眼 |

原话「不做独立购物车页」与「保留 Tab 购物车页」并存时，以**修订共识**为准。

### 策略原话（摘要）

- 购物车可做成底部模态 / 悬浮图标；点开看一眼，滑回去继续逛。
- **不做**：一级 Tab 去掉 Cart、全盘改为半屏购物车。

- 不在一级 Tab 用半屏替代 Cart Tab。
- 加购 / 同步 / 结算逻辑归属 [商品 · 顾客浏览](./商品模块-顾客浏览.md)。
