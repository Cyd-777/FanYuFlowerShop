# 词典式搜索

> **所属**：[智库模块](./智库模块.md)  
> **状态**：已迁入

## 现状

| 入口 | 匹配方式 | 强度 |
|------|----------|------|
| 百科 Tab 独立搜索框 | 云端按 preview 文字子串匹配 | 最弱 ✅ |

## 升级方向（智库 2.0 · 渐进）

- 结构化搜索：`keywords`、`aliases`、`tags`、`searchText`、`occasions`
- 特征组合：「黄色 浓香」→ 标签交集，非全文扫描
- 与 [搜索](./搜索模块.md) 统一「智库查询请求」结构（原文、分词、Tab、标签、花材编号、来源等）

## 内容优先级（P0 · 关键词）

必须覆盖顾客原话，写入 `keywords` / `searchText`：

- 能养几天、能开多久、怎么养、怎么换水、换水频率、斜剪、保鲜
- 「水养、瓶插」等可作索引，**不作页面主标题**

## 云端
