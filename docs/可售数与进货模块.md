# 可售数与进货模块

> **分层**：强化  
> **状态**：已迁入策略

## 策略

小程序里的数量是**「愿意在线上卖的数量」**，不是 WMS。商家通过进货单、批量操作维护可售数，支撑三环闭环第一环。

### 全局边界（门面售货）

- **门面售货，不做仓储系统** — 不追求采购批次、成本核算、完整 WMS。
- 与 [商品 · 商家管理](./商品模块-商家管理.md) 的 `stock` 字段联动；文案倾向「可售数量」而非「库存」。

- 仓储 WMS、采购批次、成本核算（当前阶段刻意不做）。
- 第三方物流跟踪 → [第三方配送](./第三方配送模块.md)（后置）。
