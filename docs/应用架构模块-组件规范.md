# 组件规范

> **所属**：[应用架构模块](./应用架构模块.md)  
> **状态**：已迁入（摘要）

## NutUI 接入

- 主包 `src/pages/`：**禁止** NutUI
- 分包 `pagesCustomer` / `pagesMerchant`：NutUI + `plugin-html`
- 配置见 `config/index.ts`：`NutUIResolver`、`designWidth: 375`（NutUI）vs `750`（业务页）

## 主包写法

```vue
<view class="btn" @tap="onSubmit">{{ submitText }}</view>
```

文案用 `const submitText = '提交'`，避免静态节点优化白屏。

详见 [主包分包](./应用架构模块-主包分包.md)。
