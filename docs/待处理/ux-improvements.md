# 体验优化记录

## 文档目的

1. **积累经验**：交互、加载、文案、流程上的改进动机与做法，以后遇到类似情况有参考。  
2. **项目台账**：记录本项目中**做过 / 计划做**的体验优化，方便回溯「是否已改过」；若用户再次反馈同类问题，可区分是**回归**还是**新原因**。

**与 [bugs.md](./bugs.md) 的分工**

| 文档 | 写什么 |
|------|--------|
| **bugs.md** | 重大**代码缺陷**（错数据、崩溃、白屏、编译失败等） |
| **本文** | **体验优化**、策略调整、展示与流程改进、未实现的能力设想 |

---

## 条目怎么写（模板）

每条建议包含：

- **用户侧问题**：原来哪里难用、看不懂、慢  
- **做法**：改了什么（或计划怎么改）  
- **涉及模块**：页面 / 服务 / 配置  
- **状态**：✅ 已上线 · 🔧 部分完成 · 📋 已识别待做 · 💡 仅规划  
- **若再被反馈**：先查本文是否已做过；做过仍有问题 → 记新条目并写**与上次的差异**

## 已做

### 顾客端商品局部刷新（live sync）

- **用户侧问题**：商家改价/改库存后，顾客列表要么不更新，要么整页闪、图全重载。  
- **做法**：`meta.goods` 版本驱动；仅 patch 变化字段；手势滑动触发同步（不必等抬手）。  
- **涉及模块**：`goodsLiveSync`、`applyPublicGoodsLivePatches`、`useGoodsBrowseRefresh`、`GoodsImage` 同 src 跳过重复解析。  
- **状态**：✅ 你已测过一轮 OK；Issue §17 可作回归。  
- **若再被反馈**：查 meta 是否 bump、patch 是否只改单卡、是否走了全量 `replaceItems`。

### 登录与资料流程

- **用户侧问题**：授权文案吓人；资料不应挤在「我的」页 inline 编辑。  
- **做法**：主流程改为「微信一键登录」；资料独立页 `profile/edit`；手机号登录 UI 用 `ENABLE_PHONE_LOGIN` 关闭保留代码。  
- **状态**：✅ 已上线（资料持久化属 **bug** 修正在 bugs.md）。  

### 身份码弹窗

- **用户侧问题**：打开身份码后「我的」白屏（属 bug，见 bugs.md）；弹窗宜轻量。  
- **做法**：Canvas 2D 生成二维码图；点击后再懒加载弹窗。  
- **状态**：✅  

### 商品图加载占位

- **用户侧问题**：列表等图时空白、不知是否在加载。  
- **做法**：`GoodsImage` 占位 + shimmer；失败走 `publicImage` 代理。  
- **状态**：✅（代理撞名导致错图属 **bug**，见 bugs.md）。  

### 销售标签行

- **用户侧问题**：推荐位等缺少花材种类等 contextual 信息。  
- **做法**：`GoodsSalesTagRow` + `goodsSalesTags`（新上架、推荐种类名等）。  
- **状态**：✅  

### Banner 顾客端展示（归档）

- **用户侧问题**：首页 Banner 常空白；全屏下拉刷新后才出现。  
- **排查结论**：多轮测试后倾向 **加载逻辑**（`ensure` 链未跑完 `img:banner` 即渲染），非云存储 ACL；权重调度（110 先于 recommend）为辅助修复。  
- **做法**：P0-Block 链 `shop:settings` → `img:banner` → `categories:public`（见 [data-loading §4.0](./data-loading.md#40-进页即见--定义定稿)、[DONE · 加载策略](./🎛️%20DONE.md#加载策略banner--进页即见--缓存)）。  
- **状态**：✅ 体验版多轮复测已无复现（2026-06-17 归档）。  
- **若再被反馈**：查 home `ensure` 是否 await `img:banner`、本地 `img:banner` 缓存是否有 URL；弱网边缘 case 见 DONE 复开条件。
