## 1. 整理原则（已采用）

- **不删内容** — 原有段落、清单、历史进度全部保留；只在文首加「分类 + 返回链接」
- **主文档聚焦结构** — 根目录 `README.md` 写云函数树、页面树、文件树、文档索引
- **专题文档写细节** — `setup` / `cloud` / `goods` 等继续承载操作步骤与字段说明
- **中英文** — 结构树与页面说明以**中文注释**为主；代码路径保持英文目录名
- **你 ↔ AI 分工** — [👥-feature-layers.md](./👥-feature-layers.md) 给你改进度；其余多给 AI / 开发查
- **两列信息用列表** — 文档里「键—值」类内容用 `- A — B` 横杠列表，不用两列表格（三列及以上仍可用表格）

## 5. 商品管理：阶段说明

对照库存管理 / 门面售货场景，**当前商家商品管理已覆盖第一阶段**：

- 主数据 CRUD、分类、花卉选品  
- 上下架、推荐、可售数维护  
- 批量删除 / 批量上下架 / 批量推荐  
- 进货单式「批量增加可售数」  
- 口语化范围搜索（上架、推荐、价格区间等）  

**尚未做或属第二阶段**（文档与 Issue #1 中已有列举，此处不展开实现细节）：

- 列表分页、大规模性能优化  
- 顾客端热字段实时刷新（live sync 完善）  
- 批量「设为 N」可售数、批量改价弹层恢复  
- 仓储 / 采购 / 批次（刻意不做 WMS）  

你在 [👥-feature-layers.md](./👥-feature-layers.md) 第二节「商品管理展开」里改标记即可，不必搬回 README。
