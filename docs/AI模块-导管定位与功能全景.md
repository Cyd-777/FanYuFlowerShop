# AI 导管 — 定位与功能全景

> **关联**：§7.2 AI 导管 · 智库模块 · 自选花束与导购策略  
> **更新**：2026-07-07

---

## 一、AI 导管的定位

AI 模型在整个系统中**不是大脑，不做决策，不生成内容**。它只做一件事：**把非结构化的输入（图片、自然语言），转换成结构化的特征词，然后和智库的结构化标签做匹配，输出结果。**

---

## 二、AI 导管辐射的功能模块

### 1. 拍照入库（新建商品 + 表单预填充）

| 环节 | 说明 |
|------|------|
| **输入** | 用户拍摄的花束/花材照片 |
| **导管作用** | 图像识别 → 特征词（"黄色、卷瓣、浓香"）→ 同义词映射 → 智库标签匹配 |
| **输出** | 自动填写**新建商品表单**：品类、品种、花语、养护指南、默认价格、建议分类 |
| **用户感知** | 拍一张照 → 商品表单自动填充 → 用户只需点"确认上架" |

### 2. 语义搜索

| 环节 | 说明 |
|------|------|
| **输入** | 用户口语化搜索（"送长辈的花"、"素雅一点的白色花"） |
| **导管作用** | 将口语匹配到智库 `occasions`、`tags` 等结构化字段 |
| **输出** | 匹配的花卉词条 / 在售商品 |

### 3. 隐式推荐（自主性偏差）

| 环节 | 说明 |
|------|------|
| **输入** | 用户当前浏览、历史购买、收藏记录 |
| **导管作用** | 当前商品 tags × 用户行为特征向量 → 相似度计算 |
| **输出** | 详情页"看了这束花的人还看了"、词条底部"用这个花材做成的花束" |
| **用户感知** | "是我自己发现的"，不是"被算法推荐了" |

### 4. 图片数量识别（入库辅助）

| 环节 | 说明 |
|------|------|
| **输入** | 拍摄一捆花的根部照片 |
| **导管作用** | 物体计数 API 识别茎干数量 |
| **输出** | 自动填写商品库存数量 |

### 5. 智库词条自动预填充

| 环节 | 说明 |
|------|------|
| **输入** | 输入新品种名（如"卡布奇诺玫瑰"） |
| **导管作用** | 维基百科/GBIF API 获取植物学分类 → 特征词匹配智库标签 → 预填字段 |
| **输出** | 词条编辑页自动预填，编辑只需修改 |
| **用户感知** | 输入品种名 → 点"自动填充" → 大部分已填好 |

### 6. RAG 向量生成

| 环节 | 说明 |
|------|------|
| **输入** | 智库词条全文（品种描述、养护指南、花语、问答对） |
| **导管作用** | 向量模型将词条内容转为 embedding 向量，存入向量数据库；用户提问时同样转为向量，做语义相似度检索 |
| **输出** | 搜索/问答时返回最相关的智库词条片段，而非关键词匹配 |
| **用户感知** | 搜"花蔫了怎么办"→ 直接命中养护指南中相关段落 |

## 智库图片来源

### iNaturalist Open Dataset（官方开放数据集）

iNaturalist 将所有 **Creative Commons 许可** 的观察图片公开托管在 AWS S3：

```
https://inaturalist-open-data.s3.amazonaws.com/photos/[photo_id]/medium.[extension]
```

| 特性 | 说明 |
|------|------|
| 数据量 | 数千万张 CC 许可图片，覆盖数万物种 |
| 更新频率 | 每月更新一次 |
| 获取方式 | AWS CLI 或 HTTP 直接下载，不限速不封禁 |
| 配套数据 | CSV 文件记录每张图片对应的物种 ID、摄影师、许可证类型 |
| 许可要求 | CC BY 协议图片须标注摄影师署名 |

### 筛选策略

1. 按智库现有品种名（`kindName` + `varietyName`）匹配 iNaturalist 物种
2. 每品种取置信度/质量最高的前 N 张
3. 下载后上传至小程序云存储
4. **署名**：在智库词条详情底部与词条 ID 一同展示（`图片来源：摄影师名 · iNaturalist · CC BY`）

## 三、AI 导管依赖的基础设施

| 基础设施 | 作用 |
|---------|------|
| **智库标签化** | `tags` 字段（颜色、花型、香气、场景），特征词有地方可匹配 |
| **同义词映射字典** | "金黄"→"黄色"，"浓香"→"强香"，口语对齐标准标签 |
| **智库问答对（qaList）** | 用户问"花期多久"，AI 匹配 `keywords` 直接返回答案 |
| **智库别名（aliases）** | "月季"也能搜到"玫瑰"，"扶郎花"→"非洲菊" |
| **搜索全文索引（searchText）** | 云函数自动拼接各块正文，兜底全文搜索 |

## 四、AI 导管完整链路

```
用户输入（图片/自然语言/行为数据）
        │
        ▼
  图像识别API / 语义解析 / 行为特征提取
        │
        ▼
  特征词（黄色、浓香、送长辈、丝绒质感）
        │
        ▼
  同义词映射 + 智库标签匹配（AI导管核心）
        │
        ▼
  匹配结果（品种名、词条内容、商品ID）
        │
        ▼
  应用层输出（表单填充/搜索结果/推荐列表/库存数量）
```

## 五、AI 导管不做什么

| 不做的 | 原因 |
|--------|------|
| 不生成花语、养护指南等原创内容 | 智库是权威信息的模板填充 |
| 不做聊天式对话 | 搜"玫瑰花期多久"直接返回答案，不需要多轮对话 |
| 不替代人工审核 | 拍照入库后仍需确认，AI 只预填不直接上架 |
| 不分析用户隐私数据 | 行为数据只用于本地模型匹配，不上传不分析 |

---

## 六、一句话总结

AI 导管在整个项目中只做三件事：**看懂图、听懂话、对得上号**。它把用户模糊的输入翻译成结构化标签，和智库这个"花卉字典"做匹配，输出给商品入库、搜索、推荐、养护问答等功能使用。**整个过程不生成任何新内容，只做精确的语义连接。**
