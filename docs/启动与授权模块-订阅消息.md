# 订阅消息

> **所属**：[启动与授权模块](./启动与授权模块.md)  
> **官方**：[订阅消息开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/subscribe-message.html) · [requestSubscribeMessage](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/subscribe-message/wx.requestSubscribeMessage.html) · [subscribeMessage.send](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/mp-message-management/subscribe-message/sendMessage.html)

## 官方三步

| 步骤 | 做什么 | 本项目 |
|------|--------|--------|
| 一、获取模板 ID | 公众平台配置订阅消息模板 | 见下方「步骤一」 |
| 二、获取下发权限 | 用户点击后调 `wx.requestSubscribeMessage` | 登录页一键登录 · `src/utils/bizNotifySubscribe.ts` |
| 三、下发消息 | 服务端 `subscribeMessage.send` | 云函数 `notify` · `send` 时推送 |

**没有**类似 App 的「通知总开关」API；只有**按模板的一次性订阅**（用户每同意一次，可发一条）。

## 步骤一：公众平台获取模板 ID

1. 登录 [微信公众平台](https://mp.weixin.qq.com)（小程序管理员）
2. **功能 → 订阅消息**
3. **公共模板库** → 搜索场景，例如：
   - 「业务处理通知」「工单处理通知」「订单状态提醒」等
4. 点 **选用** → 勾选关键词（至少 2 个、最多 5 个）→ 提交
5. 在 **我的模板** 里复制 **模板 ID**（形如 `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`）

若无合适模板：**公共模板库** 搜不到时可 **申请新模板**，审核约 1～7 天（多数账号只能 **选用**，见下方「公共模板库怎么选」）。

### 公共模板库怎么选（只能选用时）

> 公共模板库列表 **因小程序服务类目而异**，Agent 无法看到你的后台；按下面步骤在 mp.weixin.qq.com 操作即可。

**路径：** 功能 → 订阅消息 → **公共模板库** → 搜索 → **选用** → 勾选关键词（2～5 个）→ 填场景说明 → 提交 → **我的模板** 复制模板 ID。

#### 我们代码要填什么

每条推送固定 3 段（见 `subscribeMessage.js`）：

| 代码字段 | 含义 | 字数 | 应选关键词类型 |
|----------|------|------|----------------|
| 第 1 段 `title` | 通知类型/标题 | ≤20 | **事物 thing**（优先）或 字符串 character_string |
| 第 2 段 `body` | 详情摘要 | ≤20 | **事物 thing**（必须，勿用 phrase 当主详情） |
| 第 3 段 `fromName` | 来源 | ≤10 | **姓名 name**（没有 name 时可用 thing，填「系统」） |

**勿选：** `phrase`（汉字 **仅 5 字**）作第 2 段——我们的正文常超过 5 字，会截断或报 `47003`。

#### 搜索词优先级（只选 **1 个** 模板即可）

| 优先级 | 公共模板库搜索词 | 选用时勾选关键词（按顺序） | 说明 |
|--------|------------------|---------------------------|------|
| **★ 首选** | `工单处理通知` 或 `业务处理通知` | **工单类型** + **处理进度**（或「温馨提示」）+ **处理人** | 多为 thing+thing+name，和代码最贴 |
| **★ 首选** | `待办事项提醒` | **待办事项** + **温馨提示** + **通知人**（或「处理人」） | 同上 |
| **备选** | `订单状态通知` | **订单编号** + **温馨提示** + **处理人** | 第 1 段是单号不是标题，但能覆盖订单场景；**不要勾「订单状态」phrase** |
| **备选** | `服务进度通知` | **服务名称** + **进度说明** + **服务人员** | 看类目是否出现 |
| 不推荐单独用 | `发货通知` / `取货提醒` | — | 只覆盖单一环节，库存预警对不上 |

花店常见类目：**鲜花绿植**、**电商平台**、**生活服务** 等；搜不到某模板时，到 **设置 → 基本设置 → 服务类目** 补类目后再搜。

#### 场景说明（选用提交时复制）

```
用于花店小程序订单履约与库存管理：向已授权用户推送订单提交、确认、备货、配送、完成、取消及低库存、售罄提醒。非营销广告，用户于登录或「我的」页主动订阅，一次性订阅每条业务事件最多推送一条，详情在小程序消息列表查看。
```

#### 选用后必做

1. 打开 **我的模板** → 点进刚选的模板 → 看详情里的字段名（如 `thing1.DATA`、`character_string1.DATA`）
2. 复制 **模板 ID** + **三个字段名**（顺序对应：标题 / 正文 / 来源）
3. 若字段名 **不是** `thing1,thing2,name3`，配云函数环境变量：

   `BIZ_NOTIFY_SUBSCRIBE_FIELD_KEYS=实际字段1,实际字段2,实际字段3`

   例：订单状态通知选了「订单编号+温馨提示+处理人」可能是  
   `BIZ_NOTIFY_SUBSCRIBE_FIELD_KEYS=character_string1,thing2,name3`

4. 同步部署：`npm run sync:cloud && npm run push:cloud -- --only notify --yes`

#### 各模板勾选示例（复制对照）

**A · 工单处理通知（最推荐）**

勾选：**工单类型** · **处理进度** · **处理人**  
预期字段：`thing1` · `thing2` · `name3` → **不用改** `BIZ_NOTIFY_SUBSCRIBE_FIELD_KEYS`

**B · 订单状态通知（类目里最常见）**

勾选：**订单编号** · **温馨提示** · **处理人**  
❌ 不勾：订单状态（phrase 太短）  
预期字段：`character_string1` · `thing2` · `name3`  
环境变量：`BIZ_NOTIFY_SUBSCRIBE_FIELD_KEYS=character_string1,thing2,name3`  
（第 1 段会发「订单 FY…」或「新订单」，第 2 段发完整摘要）

### ~~自定义模板文案~~（仅「申请新模板」可用时）

申请 **新模板** 时，标题与关键词建议如下，与现有云函数 **零改代码**（字段名 `thing1` / `thing2` / `name3`）。

**模板标题（≤15 字）**

```text
订单与库存提醒
```

**模板内容（正文，按顺序添加 3 个关键词）**

```text
通知类型：{{thing1.DATA}}
通知内容：{{thing2.DATA}}
来源：{{name3.DATA}}
```

| 序号 | 关键词名称 | 关键词类型 | 说明 |
|------|------------|------------|------|
| 1 | 通知类型 | **事物**（thing） | 对应代码 `title`，≤20 字 |
| 2 | 通知内容 | **事物**（thing） | 对应代码 `body`，≤20 字 |
| 3 | 来源 | **姓名**（name） | 对应代码 `fromName`，固定多为「系统」，≤10 字 |

**服务场景说明（申请理由，可粘贴）**

```text
花店小程序向顾客与商家推送订单状态变更（下单、确认、备货、配送、完成、取消）及库存预警（低库存、售罄）的业务提醒。用户登录或于「我的」页主动授权后，每条业务事件最多推送一条微信服务通知；详情在小程序内消息列表查看。
```

**审核通过后**：在 **我的模板** 复制模板 ID → 配 `BIZ_NOTIFY_SUBSCRIBE_TMPL_ID` 与 `src/config/subscribe.ts`（见步骤二）。

**用户在微信里看到的示例**

| 场景 | thing1（通知类型） | thing2（通知内容） | name3（来源） |
|------|-------------------|-------------------|---------------|
| 顾客下单 | 订单 FY… | 已提交，等待商家确认 | 系统 |
| 商家新单 | 新订单 | 花友 · 红玫瑰 等2件 | 系统 |
| 商家确认 | 订单 FY… | 商家已确认，正在准备 | 系统 |
| 低库存 | 库存偏低 | 「红玫瑰」剩余 3 | 系统 |
| 售罄 | 商品售罄 | 「红玫瑰」库存已归零 | 系统 |

> 若公众平台生成的字段名不是 `thing1/thing2/name3`（例如 `thing4/thing5/name1`），把 **我的模板** 里实际字段名发给开发，改 `cloudfunctions/common/subscribeMessage.js` 的 `SUBSCRIBE_FIELD_KEYS` 后 `npm run sync:cloud && npm run push:cloud -- --only notify --yes`。

### 与本项目云函数字段对齐

当前 `cloudfunctions/notify/index.js` 默认映射：

| 云函数字段 | 建议模板关键词类型 | 内容 |
|------------|-------------------|------|
| `thing1` | 事物（thing） | 通知标题，≤20 字 |
| `thing2` | 事物（thing） | 通知正文摘要，≤20 字 |
| `name3` | 姓名（name） | 发送人，≤10 字 |

选用模板时，尽量选含 **2 个 thing + 1 个 name** 的组合；若关键词名不同，需改云函数 `SUBSCRIBE_FIELD_KEYS`。

> **长期订阅**仅对部分类目（政务、医疗等）开放；花店一般用 **一次性订阅** 即可。

## 步骤二：写入本项目配置

**至少配一处**（推荐两处都配，保持一致）：

### A. 云函数环境变量（发消息必需）

云开发控制台 → **云函数 `notify` → 配置 → 环境变量**：

| 变量 | 值 |
|------|-----|
| `BIZ_NOTIFY_SUBSCRIBE_TMPL_ID` | **我的模板** 复制的模板 ID |
| `BIZ_NOTIFY_SUBSCRIBE_FIELD_KEYS` | 可选；默认 `thing1,thing2,name3`；选用「订单状态通知」等时改为实际字段名，逗号分隔 |
| `MINIPROGRAM_STATE` | 可选：`formal`（正式）/ `trial`（体验）/ `developer`（开发） |

部署：

```bash
npm run sync:cloud
npm run push:cloud -- --only notify --yes
```

云函数 `notify/config.json` 已声明 openapi 权限：`subscribeMessage.send`。

### B. 小程序前端（登录弹窗必需）

`src/config/subscribe.ts`：

```typescript
export const BIZ_NOTIFY_SUBSCRIBE_TMPL_IDS: string[] = [
  '与上面相同的模板ID',
]
```

登录页会先 prefetch；若此处为空，会再调云函数 `getSubscribeConfig` 拉 ID。**两处都空则不会弹授权窗**，只会直接登录。

## 步骤三：前端授权（登录时弹窗）

官方要求：**用户点击行为之后**才能调起订阅界面（[API 说明](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/subscribe-message/wx.requestSubscribeMessage.html)）。

本项目流程：

1. 进入登录页 → 按钮「准备中...」（拉模板 ID）
2. 点 **微信一键登录** → `wx.requestSubscribeMessage({ tmplIds: [...] })`
3. 用户点允许/拒绝 → 再执行登录

```javascript
// 官方最小示例（本项目封装在 invokeBizNotifySubscribe）
wx.requestSubscribeMessage({
  tmplIds: ['你的模板ID'],
  success(res) {
    // res['模板ID'] === 'accept' | 'reject' | 'ban'
  },
})
```

### 用户勾选「总是保持以上选择」

之后可能不再弹窗，但接口仍会返回上次选择；改主意需：**小程序右上角 … → 设置 → 订阅消息**。

## 步骤四：服务端发送（同事发通知时）

用户 `accept` 后，云函数在 `notify` · `send` 时调用：

```javascript
cloud.openapi.subscribeMessage.send({
  touser: openid,
  templateId: BIZ_NOTIFY_SUBSCRIBE_TMPL_ID,
  page: 'pagesCustomer/notify/list',
  data: { thing1: { value: '...' }, thing2: { value: '...' }, name3: { value: '...' } },
})
```

消息出现在微信 **服务通知**（不是聊天列表）。

### 常见错误码

| 码 | 含义 |
|----|------|
| `43101` | 用户未订阅或一次性额度已用完 → 需重新点登录/我的页授权 |
| `47003` | 模板参数不匹配 → 检查 thing/name 字段与模板关键词 |
| `20004` | 用户关闭了订阅消息主开关 |
