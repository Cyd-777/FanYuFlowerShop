## 能力

- 数量选择、加购前云端校验（`validateGoodsForPurchase`）
- 加购 composable（详情、收藏复用）
- 商家多图：编辑页网格上传，详情轮播展示
- 售罄 / 下架区分：`onSale` 控制下架隐藏；`stock=0` 仍展示并标注「售罄」

## 云端

- `goods.publicGet` — 顾客端详情
- `favorite.check` / `add` / `remove` — 收藏态
