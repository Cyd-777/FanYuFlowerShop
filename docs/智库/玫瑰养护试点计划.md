# 玫瑰养护试点计划

> **范围**：仅「怎么养」Tab · **玫瑰** 分类（24 品种 + 1 种类条）  
> **不做**：图鉴/花语例文全量、其它 19 个种类

## 目标

1. **养护词条齐备**：wakeUp、日常换水/修剪/水深、environment（含 avoid 乙烯）、保鲜剂、急救
2. **玫瑰全品种有底稿**：继承 `ROSE_CARE_BASE`，无需逐个写长文
3. **3 个试点品种验证 override**：弗洛伊德、卡罗拉、艾莎

## 数据结构（代码）

| 文件 | 作用 |
|------|------|
| `cloudfunctions/wiki/wikiRoseCare.js` | 玫瑰养护底稿 + 品种 override |
| `cloudfunctions/wiki/wikiCarePick.js` | 字段合并 |
| `cloudfunctions/wiki/wikiVarietyArticles.js` | 弗洛伊德图鉴/花语（养护走 wikiRoseCare） |

## 齐备检查项

- `careVase.summary`
- `careVase.wakeUp.steps[]`
- `careVase.waterChange` / `trim` / `waterDepth`
- `careVase.environment`（含 `avoid[]`）
- `careVase.additives`

## 本地验证

```bash
node scripts/audit-wiki-rose-care-local.js
```

应输出 24/24 齐备。

## 写云库（仅玫瑰养护）

```bash
npm run deploy:cloud -- --only wiki
npm run sync:wiki-rose-care
node scripts/audit-wiki-db.js   # 看 hasWakeUp 是否 > 0
```

`syncRoseCare` **只更新** `kindName=玫瑰` 的 `careVase` / `bloom` / `searchText`，不动其它种类。
