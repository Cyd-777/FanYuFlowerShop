# 设计令牌参考

> **所属**：[样式体系模块](./样式体系模块.md)  
> **源码文件**：`src/styles/tokens.less`

---

## 三层架构

```
L1 原始色阶  ──  Tailwind CSS 色板（red-50 ~ gray-900）
    │
    ▼
L2 语义令牌  ──  品牌 / 功能 / UI 含义（@color-brand、@color-success…）
    │
    ▼
L3 组件令牌  ──  具体组件引用（@color-tab-selected、@radius-md…）
```

**规则**：
- 页面/组件样式只用 `@变量名`，禁止写十六进制色值
- 换肤只改 L1 或 L2，组件层不需要动
- 旧名 `@color-primary` 等通过兼容别名自动映射到 L2，不需要改已有组件

## 兼容别名（旧名 → 新名）

以下别名确保三层令牌迁移后旧组件无需改代码：

| 旧名 | 映射到 | 相当于 |
|------|--------|--------|
| `@color-primary` | `@color-brand` | `@red-600` |
| `@color-primary-light` | `@color-brand-light` | `@red-50` |
| `@color-primary-border` | `@color-brand-border` | `@red-200` |
| `@color-primary-bg-alt` | `@color-brand-bg-alt` | `@red-50` |
| `@color-green-mid` | `@green-600` | `#43a047` |

新组件请直接使用 L2 语义令牌，不要使用兼容别名。

## 使用示例

```less
// 页面背景
.page-foo {
  background: @color-bg-page;
}

// 品牌主色按钮
.btn-primary {
  background: @color-brand;
  color: #fff;
  border-radius: @radius-md;
  font-size: @font-size-lg;
}

// 成功/失败标识
.tag-success { color: @color-success; background: @color-success-bg; }
.tag-danger  { color: @color-danger;  background: @color-danger-bg; }

// 文字层级
.title   { color: @color-text-primary; }
.desc    { color: @color-text-secondary; }
.hint    { color: @color-text-tertiary; }
.disabled { color: @color-text-disabled; }
```
