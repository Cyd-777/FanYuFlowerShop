# 模块分类 — 基础业务与强化业务

> 从功能层面区分：**基础模块**是花店应用必备的功能单元，**强化模块**是在基础之上的增值能力。

---

## 🟢 基础业务模块（花店应用必备）

花店小程序能跑起来的最小集。

| 模块 | 说明 |
|------|------|
| **商品** `goods` | 商品 CRUD、上下架、搜索 |
| **分类** `category` | 商品分类管理 |
| **订单** `order` | 下单→支付→状态流转 |
| **购物车** `cart` | 加购、数量、结算 |
| **会员** `member` | 等级、积分、签到 |
| **地址** `address` | 配送地址管理 |
| **员工/权限** `staff` + `auth` | 人员管理、登录鉴权 |
| **店铺** `shop` | 店铺名称、设置 |
| **通知** `notify` | 订单通知、订阅消息 |
| **收藏** `favorite` | 顾客端收藏 |
| **搜索** `search` | 关键词搜索（商品+智库） |
| **花卉库** `flower` | 基础花卉品种数据 |

---

## 🔵 强化业务模块（增值能力）

基础之上的差异化能力。

| 模块 | 说明 |
|------|------|
| **🤖 AI 导管** `ai` | DeepSeek 导购推荐 + 语义搜索解析 |
| **📚 智库** `wiki` | 花卉百科词条（品种/养护/花语），含商户端维护 |
| **🎯 推荐引擎** `recommend` | 基于 rules + AI 的花束搭配推荐 |
| **🏭 仓储流水** `warehouse` | 入库/出库/历史流水追踪 |
| **🖼️ 素材管理** `asset` | 图片等素材的云端管理 |
| **📈 销售策略** `salesStrategy` | 折扣/满减等营销配置 |
| **👤 用户画像** `userProfile` | 用户头像等扩展信息 |

---

## 🧱 横向基础设施（支撑层）

| 单元 | 说明 |
|------|------|
| **🎨 令牌系统** `tokens.less` | 三层设计体系（L1 色阶 → L2 语义 → L3 组件） |
| **⚡ 缓存/预取** `data/` | 多级缓存 + 页面数据编排 + 预取调度 |
| **🧩 组件库** `components/` | 30+ 通用组件（导航/搜索/卡片等） |
| **🔧 Composable** `composables/` | 29 个可复用逻辑（滚动联动/上拉刷新等） |
| **✅ 代码质量** `scripts/` | 模块边界/耦合度/模板合规/死链检测 |
| **☁️ 云函数** `cloudfunctions/` | 20 个云函数，每个业务模块对应一个 |

---

## 🔗 核心强化模块调用关系

```
搜索页 → search(搜索) ─→ ai(语义解析) ─→ goods + wiki
导购页 → recommend(推荐) ─→ ai(推荐) ─→ DeepSeek
首页   → recommend(推荐) ─→ ai(推荐)
wiki页 → wiki(智库) ─→ ai(语义搜索) [待接]
```

AI 是强化模块的核心，串联搜索、推荐、智库三条业务线。
