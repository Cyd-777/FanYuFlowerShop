# 微信支付模块

> **分层**：业务  
> **状态**：已迁入策略（暂停）

## 策略

顾客在线完成支付；与主体 AppID / 个体工商户方案绑定后接入。

### 过渡策略（当前）

- 本阶段**不接入**；订单创建即「待处理」，商家线下收款。
- 主体：当前个人身份小程序 ID；标准主体迁移走不通时，后续切换个体户 ID 或重新发布。
- 代码预留：订单提交用配置变量 — `false` 显示「联系客服下单」，`true` 显示微信支付。

### 策略原话（摘要）

- 自配送 / 自提到店手续费约 0.6%；第三方平台有配送费消耗。
- 没接配送、不支持支付时**不对外推**体验版；先在鲜花群测试。

- **刻意后置**，等 AppID / 方案确定；**不挡** 0.2.0 改号。
- 与 [第三方配送](./第三方配送模块.md) 同属后置大模块。
