# 0.1.x 版本线（当前）

**文档锚点**：`0.1.0`（minor 基线说明，下同统称 0.1.x）  
**当前状态**：**进行中** — 版本号仍在 0.1.x（`package.json` 为 `0.1.4`）  
**Git 标签**：`v0.1.0`（早期发版点；其后提交仍计在 0.1.x 内）  
**推进目标**：完成 [0.2.0.md](./0.2.0.md) 中的必做项后，才将版本号定为 **0.2.0**

---

## 版本定位

0.1.x 阶段的核心是：**能上架、能逛、能装店**。顾客可浏览与加购，商家可维护商品与店铺形象。

三环经营闭环（下单 → 商家接单 → 完成）**不属于已发布的 0.1.x 版本号**；相关代码若在分支上开发，属于**向 0.2.0 推进的工作**，在发版改号之前仍视为 0.1.x 时期的开发。

---

## 0.1.x 已具备（相对 v0.1.0 标签，含后续 0.1.4 等提交）

### 身份与登录

- 微信一键登录、OpenID、商家 / 顾客角色、按角色跳转
- 身份码展示与复制；身份码二维码弹窗
- 人员管理（`staff`）；扫码核销页骨架

### 商家端

- 工作台、`initDb`、店铺设置与销售策略 / 主题装潢
- 分类与商品 CRUD、花卉选品、列表筛选

### 顾客端

- TabBar：首页 / 商城 / 百科 / 购物车 / 我的
- 商品浏览、加购、购物车、定制花束、收藏、百科
- 会员相关页面骨架（业务未完整）

### 横切

- 云开发、SWR 缓存、主包 / 分包架构

## 0.1.x 正式发版时仍不包含（归 0.2.0 目标）

以下能力**只有完成 [0.2.0 发版条件](./0.2.0.md) 并改号后**，才算进入 0.2.x 版本线：

- 订单创建、列表、详情、商家接单 / 完成
- 地址上云、微信地址导入
- 商品批处理、进货单加可售数（及为闭环配套的商家能力）
- 微信支付、会员 / 优惠券、完整核销

分支上若已有部分实现，属于**未发版的开发进度**，不改变当前 **0.1.x** 的版本号认定。
